## 1. 护栏现状与失效机理

### 1.1 护栏是什么、拦什么
`test_tick_overhead_delta_sanity`（非 bench，每提交 CI 跑）：
```python
delta_ms = _paired_delta(baseline, injected, iters=40) * 1000.0
assert 0.02 <= delta_ms <= 2.0
```
`_paired_delta` 交替 tick 相减，`injected.tick(1)` 减去 `baseline.tick(1)`，再 `/iters`（**均值**）。
- **过低（<0.02）**：独白分支被短路——`willingness_expression` 返回 None、无独白事件 ⇒ 注入≈基线（实测 band=0 增量 ~0.004ms）。
- **过高（>2.0）**：独白事件构造退化（payload/序列化膨胀）⇒ 需重定标。

### 1.2 为什么偶发越界：均值的离群敏感性
配对相减**本意**是抵消墙钟漂移，但它只能抵消**两边同时**的漂移；单次**上下文切换/GC 只落在 injected 侧**时，该次配对差成为多 ms 离群，且**均值**会被它拖离真值。

**实测（2026-10-01，本机暖态，throttle_ratio=1.652 健康）**：

| 口径 | 值 | 说明 |
|---|---|---|
| 逐对增量**中位** | **~0.21ms** | 稳定代表真实注入成本 |
| 逐对增量**均值** | **~0.47ms** | 被极端离群（max **~9.6ms**）拉高 |
| 均值越界概率 | 逐对里 >2.0ms 的离群可到 **3/60** | 均值=0.21+（Σ离群）/60 ⇒ 数个离群即可超 2.0 |
| 中位越界概率 | **0** | 中位不受离群影响 |

- 干净机（无人工争用）均值 0.47ms/max 9.6ms；CPU 争用（核-1 满转）下均值更不稳、**中位仍 ~0.25ms**。
- 合成「5% 概率注入侧 3ms 抢占」：均值 0.40ms（被抬），中位 0.21ms 不变。

⇒ **失效根因是「用均值估计一个小量」**，不是窗口值错。这也正是「CPU 争用时脆弱」的机理（A4 报）。

## 2. 三选一评估

### Option 1：放宽窗口
- 说明：把 [0.02, 2.0] 改成更宽（如 [0.005, 10]）。
- 优点：改动最小。
- 缺点：**治标不治本**——离群仍会随负载把均值推来推去，宽到「永不越界」就必须牺牲「事件构造退化」的判别力（1.1 的过高方向）。真实信号 0.21ms 远离两端，窗口本身合理。
- **不推荐**。

### Option 2：改单调性判据（Δ 趋势而非绝对值）★推荐
- 说明：把断言从「均值落在绝对窗口」改为「**逐对增量中位**落在同一窗口 0.02–2.0ms」。
- 机理：中位**只关心 Δ 的典型符号与量级（趋势）**，对离群免疫。Σ 中位 = 注入**一致地**比基线慢（+0.21ms）⇒ 短路时中位≈0.004ms 仍 <0.02（拦得住）；构造退化时中位远超 2.0（拦得住）；单次抢占影响不了中位（防误报）。
- 优点：**不改任何窗口值**（0.02–2.0 照旧），只换稳健估计量；保留两端判别力；对 CPU 争用鲁棒。
- 实测：干净机 10/10 过；CPU 争用（核-1 满转）5/5 过；合成抢占下中位稳定。
- **推荐**。

### Option 3：维持 + 文档登记抖动前提
- 说明：代码不动，在 docstring 写明「CPU 争用下可能越界，属平台抖动」。
- 优点：零改动。
- 缺点：一个**在每提交 CI 硬断言**的护栏会**间歇性红灯堵门禁**（A4 已实际受扰）。文档化缓解不了一条已发生的 CI 红；且收敛在「接受抖动」而非「消除误报」。
- **不推荐**（可作为 Option 2 的补充说明，不作为主方案）。

## 3. 推荐实现（Option 2）

### 3.1 改动
`sim/tests/bench/test_bench_willingness.py`：
- `_paired_delta`（返回均值 float）→ `_paired_deltas`（返回逐对增量 list），同义改名，无外部调用者（grep 确认仅本测试用）。
- 护栏 `delta_ms = statistics.median(_paired_deltas(baseline, injected, iters=60)) * 1000.0`；断言窗口 0.02–2.0ms 不变。
- `import statistics`。
- docstring 补「中位抗离群」机理与实测数字（A4 报的偶发越界）。

### 3.2 不动的
- `WILLINGNESS_TICK_LIMIT_MS = 0.35`（thresholds.py，红线，非本单对象）。
- 窗口上下界数值（0.02 / 2.0）。
- 引擎/API/前端代码。
- `nightly-bench.yml`、`baseline-epyc7763.json`。

### 3.3 验证
- 护栏 10/10 通过（干净）；争用（核-1 满转）5/5 通过；`test_bench_willingness.py` 整文件 17 passed。
- `ruff` All checks passed；`pyright` 0 errors。
