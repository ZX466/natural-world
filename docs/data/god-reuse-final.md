## 1. 一句话结论

**GOD 最值钱的不是它的仿真框架（临河镇的内核更好），而是两样东西：把一次运行变成一个链接的静态回放导出（能力面），和两个几乎为临河镇量身定做的古风素材包（素材面）。前者建议立项，后者已完成选片收集。**

## 2. 能力利用（A–D 级）

| 级 | 内容 | 结论 | 时机 |
|---|---|---|---|
| **A** | **静态回放导出**：`public_replay_export.py` 把运行从 SQLite 导出为静态 JSON + 素材，GitHub Pages 托管，浏览器打开即看、无安装无 key | **建议采纳**。无架构冲突（`outbound_guard` 纯函数可直接复用做「只导叙事化帧」）。服务长跑验收呈现（真实 20 差事长局人审回看）、T4 探针取证、分享传播 | 验收深度阶段即可立项 |
| **B** | **地图包语义**：`map.yaml` 的 `locations + anchor_tile + aliases + interactions`；aliases（"home"/"house"/"住所" 同义）对 NPC 语言理解与 prompt 地标指代有参考价值 | 采纳**格式思想**（非代码，零授权义务），对齐进 `sim/content/` 地标规范 | M6 内容阶段顺手做 |
| **C** | **/ask 定向提问**：向某 agent/群组/全镇提问 | 临河镇版本更优：点击村民 → LOD 升格 L2 → 第一人称回答（受知识边界约束）→ 降格写回记忆。与念头注入不冲突（对象是 NPC 不是主角） | M6 玩法增量 |
| **D** | 实验包目录约定（`quick_experiments/<hypothesis>/<experiment>/` + ZIP 导入导出） | 仅备档，等 L3 层验收（LLM 裁判/人类盲测）需求出现再议 | 不排期 |

**明确不引入**（能力面三红线）：
- `agentsociety2` 框架本体——松散 step 循环，无事件溯源/确定性/出站闸，移植等于降级临河镇地基
- `/intervene` 干预机制——上帝指令直改下一步，与「玩家只是直觉」（DESIGN §9/§10）直接冲突
- jiuwenclaw / Setup 向导 / 各 Studio——场景无关或临河镇完成度更高

## 4. 工程接入约束（素材入游戏的既定事实）

| 维度 | 临河镇现状 | GOD 素材 | 解法 |
|---|---|---|---|
| tile 尺寸 | `TILE = 16`（WorldScene.ts:21） | 32px | 缩半入 16px 管线（前端零改动）或项目整体升 32px（全链重制，留美术打磨阶段）——**待裁决 D1** |
| 角色帧 | 16×32 头身比 | 96×128 sheet（约 32×32 帧） | 重切 16×32（建议）或村民转 16×16 chibi（与主角帧高不一致需统一裁决）——**待裁决 D2** |
| 精灵格式 | 自定义 SheetGeometry | Phaser 原生 atlas JSON | content 管线加 atlas 适配即可，前端零改动 |
| 素材管线 | build_palette.py 单一真相源 | — | 新素材必须走管线登记，禁止手撒 PNG |
| 协议面 | villagers.py 名册 → sprite id 前端静态映射 | — | 零协议变更，与 C3 无冲突 |

## 6. 合规与署名义务

- **用 GOD 生成素材**（桃花源/空城计/PKU）：Apache-2.0 要求保留版权与许可声明——落点：`sim/content/README.md` 素材清单新行（来源/许可/署名/落点）+ 仓库级 THIRD-PARTY-NOTICES（引入代码段必加；纯素材从严两个都做）
- **用 the_ville 任何素材前**：先核验 LimeZu/pipohi 上游条款；PixyMoon 名下一律视为未购买不可用
- **只借鉴交互思路**（静态回放、/ask、地图包组织）：无版权义务；**引入任何代码段**：须带原版权与许可声明
- **素材原件不入仓库**（~66MB，gitignore 已登记）：下载源与选片规则可重建，见素材区 README

## 7. 与临河镇六条约束（C1–C6）的兼容性总账

**零冲突**：素材外观映射（前端静态）、/ask（LOD 机制延伸）、地图包语义（纯格式思想）。
**可解冲突**：A 级回放导出必须复用 outbound 投影（只导叙事化帧）+ 事件驱动关键帧控制数据量——两处都有既定解法。
**主动排除**：/intervene、框架本体、付费素材——设计/授权红线，不引入。
