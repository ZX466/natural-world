> ⚠ **本轮一处自查修正（记下来免得下次踩）**：我第一次扫 `thresholds` 导入者时用了 `bench\.thresholds|import thresholds` 这个模式，**对 bench 内部的相对 import（`from .thresholds import …`）完全失配 ⇒ 输出「零命中」的假结论**。差点把一个「C5 结论已失效」的假警报写进回执。**改成 `from\s+[\.\w]*\s*thresholds\s+import|import\s+thresholds` 后得到正确的 12 个**。
