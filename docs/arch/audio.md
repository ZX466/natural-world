# 世界音效

音效是纯客户端表现，从既有 `state_delta` 的人物位置、`voxel_edits.action`、结构相位与
`combat_event` 和既有光源生命周期派生。当前协议为 1.18，未增加 npm 依赖或音频文件。
本通道只管理自己的增益、滤波器、短噪声缓冲和音源；Phaser 路径复用引擎上下文，
Three 路径由世界场景管理独立上下文。

## 默认行为与入口

每次打开页面默认**静音**，音量预设 **25%**，不持久化启用状态。在“模型设置”页的
“世界音效”勾选“开启音效”，回场景点击或按键后才解锁并发声。设置本身不解锁上下文；
回放首快照、心声、计划、任务/错误提示不会发声。切出窗口、断线、静音或场景销毁时立即
停止自己的音源，切回窗口须再次交互。浏览器无 WebAudio 时保持静音，世界照常运行。

## 已接入的声音

- 脚步：现有角色位置确实改变且跳距不超过四格时，发出短促脚步声；人物新增、静止、
  传送和重连快照不发脚步声。更新帧的 `op` 缺省才是原协议的更新语义。
- 挖放：收到真实 `voxel_edits` 的 `dig/place` 才发声；长按意图、进度或乐观点击不发声。
- 战斗：既有可见 `combat_event` 对应衣料/挥动类短声，同一交换呈现去重；不生成语言。
- 坍塌：已知结构相位变为 `rubble` 的增量产生低频断裂声，首次快照的旧瓦砾保持静默。

以主角镜像位置为听者，八格内随距离衰减；同类短声间隔至少 120ms，后端最多八个音源，
不会因一帧几十名村民齐动而堆出几十路声音。没有听者或来源不在镜像时保持静音。

## 火场光源与声音

2026-11-09 波 B 将真实活跃火格投影为既有 `lights.kind=fire`，经镜像驱动附近的火焰循环声。
全量快照带当前光源；增量新增完整光源，熄灭时移除；不变时不发光源键，人物静止也能收到变化。
客户端保留旧的只改 `flicker` 增量，移除光源后会停止相应火声；静音、交互解锁与距离规则不变。

投影只含不透明 rtoken、位置、kind、radius、flicker 六个表现字段；半径 5、闪烁系数 0.4。
不发送 `fire.ignited` 等事件帧、内部火场标识、燃料、世界 tick 或归因信息，也不新增火灾专用路由。
重连快照不消费其他客户端待发的移除；读档和停服清除旧光源视图。该接线不增加火焰粒子或动态光影。
自动化只验证协议、镜像和声音映射，真实听感仍须用户验收。
部署时须同步加载 1.18 客户端；1.16 客户端不处理光源移除，旧火声可能持续到下一次全量同步。

## 可复现性与验收

全部缓冲由固定种子的 xorshift32 生成，再使用固定的持续时间、包络和低通滤波；不调用
`Math.random()`，无外部采样、语音合成或 BGM，也无素材授权依赖。声音不影响世界状态、
协议和模型决策；同长度/种子噪声逐字节一致。

Vitest 使用假 AudioContext 验证映射、默认静音、首次解锁、静音清理、窗口切出/晚到解锁、
断线/快照/距离守卫和资源释放。自动测试只能证明技术链路，**听感必须用户亲自验收**。
亲听入口：启动客户端 → 模型设置 → 世界音效开启、25% → 返回场景点击 → 走动、挖放。
