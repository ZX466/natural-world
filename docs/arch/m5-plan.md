## 1. 依据速览（逐条可追，行号随 DESIGN 冻结版本）

- **§2 约束 C6**：存档双轨——世界档 append-only 含所有废弃分支；玩家档只是游标；读档 = 分叉。
  **守卫测试 = T1「历史不可销毁」**（§16 六类不变量第 5 条：`before <= world.all_event_seqs()`），**落地里程碑 = M5**。
  ⇒ §17 的验收句「**C6 测试绿**」指的就是这条 T1 断言全绿，不是「C6 是第六个测试」（C1–C5 均已在 M0–M1 落地）。
- **§11 不可预测性（混合熵）**：`chaotic(stream)` 确定性流可重放 / `inject(stream, reason)` 真随机并记 `EntropyDraw` 后重新播种；
  「巧合连锁：不利事件暂时抬高后续不利概率（运气对 Agent 完全不可见）」；**熵日志只在开发模式存在**。
- **§12 双轨存档**：世界档 vs 玩家档对照表（归属/内容/操作/用途）；**读档流程**＝定位 anchor 的 (branch_id, seq)
  → 最近快照 → 重放事件 → 应用 `agent_override` → **从该点创建新分支、旧分支标记 abandoned** → 世界继续；
  快照每 1000 tick 一次、事件重放毫秒级；**体积与归档（v2.1）**＝快照 ≤5MB(gzip)、同分支仅留最近 8 份热快照 + 每日首快照、
  abandoned 分支整体冷归档、事件主库目标稳态 <2GB；**分叉可见性第一版完全隔离**（§12 明写「先埋着，不启用」）。
- **§13 NPC/LOD**：**十个现实系统分两类**——改底层四个（M1–M2 定型，砍不得）：感知传播/非理性框架/语言阶层/物质熵增；
  加内容六个（可增量，缩范围从这里砍）：**时间刻度** / 不成文规矩 / **权力牙齿** / 巧合连锁 / 身体会坏 / 生命始终。
  ⇒ **M5 命中「加内容六个」中的 3 项**（时间刻度、权力牙齿、巧合连锁的上位机制）。
- **§14 建造与破坏**：承重依赖图 → 级联坍塌 → 坍塌范围伤人 + **火灾蔓延（M5）**；
  **生态影响（砍树→水土流失→河浊→鱼少）是慢变量，M5 末位，第一个可砍**。
- **§16 测试分级**：T1 六类不变量含**历史不可销毁**（C6 守卫）；T2 回放逐位一致（C5 守卫）。
  **M5 的「离线再回来世界已变」是行为验收，不是 §16 里的某一级测试**——它需要一个可执行的离线推进判据（见 §3 批次 E）。
- **§18 缩范围顺序（先砍→后砍）**：**生态** → 火灾蔓延（保留坍塌）→ 语言阶层 → 空间迷雾 → **权力牙齿** → 生命始终 → 动物三只 → 节气。
  **永不砍**五项：感知传播引擎 / 非理性框架 / 可变地图底座 / 闸门 / 独白叙事化。
  ⇒ **M5 七件事里有 3 件（生态 / 火灾蔓延 / 权力牙齿）在缩范围序内**，是 M5 最可能被砍的部分（见 §5）。

## 2. 依赖与排序总纲

```text
M4 收官资产（建造破坏/坍塌 + 事件流 + 巧合连锁运气面 + golden T5）
   │
   ├─→ 批次 A（时间刻度 + 混沌）─┐
   │                              ├─→ 批次 D（火灾蔓延 + 生态）─┐
   └─→ 批次 B（双轨存档分叉重放）─┘                              ├─→ 批次 E（断线降级演练 + 验收收口）
              │                                                  │
              └─→ 批次 C（权力牙齿）──────────────────────────────┘
```

- **A / B / C 三者可并行起步**（分属不同模块，共享文件少）；**D 依赖 A + B**（蔓延要混沌供火源演化、跨日推进要读档/快照链）；
  **E 收口全部**（验收句「离线再回来世界已变」本身就把双轨存档 B 与断线演练 E 绑在一起）。

  它又是 T1 历史不可销毁的守卫面——**B 不绿则 §17 的「C6 测试绿」无从谈起**。
- 全部批次的地基是 M0–M4 已收口资产（事件溯源唯一写路径 / 分流 RNG + 熵注入 / chunk 可变地图 / 建造事件族 / T5 golden 脚手架）。

  **F1** `npc_profiles` 主键单列 → 复合 `(branch_id, id)` ＝ 迁移 **0008-a**（**裁 21-B 裁 1「必落」**，0006 对 `matter_state` 有可抄模板）；

  三方分工＝opencode 施工 + codex 复核 R2 红线 + pi 跑 `RETRIEVAL_*` before/after）。
  ⇒ **两条齐备 ⇒ G-6 解锁、批次 B 的分叉本体方可开工**；F1/F3 任一未落 ⇒ 批次 B 只能做零迁移断言面，不得开分叉写入。
