## 1. 依据速览（逐条可追，行号随 DESIGN 冻结版本）

- **§8 认知层**：`[输入]` 段已有「新念头」槽位；独白三形态（头顶气泡/思维面板/**计划看板**）；非理性框架含沉没成本、习惯；自主触发门控含「收到念头」；自我认知七条铁律（零元信息/视角锁定/感官封闭/记忆即身份/无存档意识/保留不可解释的间隙/必须有身体）。

- **§11 不可预测性**：注入真随机 vs 确定性混沌分工；**巧合连锁**定义；熵日志只在开发模式；分支内不可逆（失能/债务/关系破裂）。
- **§14 建造与破坏**：施工按 tick 推进（一木棚=一游戏日，受技能/疲劳/天气）；失败表现为 `quality` 低而非立即塌；承重依赖图→级联坍塌→火灾蔓延（M5）；`integrity` 归零→rubble 永不恢复并进事件日志与见证者记忆；寻路按 chunk 增量失效（禁全图重算）；存档=初始地图+tile_changed 重放；生态影响 M5 末位、第一个可砍。**未知四轴**表：因果未知=M4。
- **§15 成本治理**：单次决策 ≈1.2–2k tok；Agent 一游戏日 40–60 次决策 ≈60–120k tok；监控先行阈值后调。
- **§16 测试分级**：T1 六类不变量（**含材料守恒**）/T2 回放逐位一致/T3 闸门样本/**T4 出戏探针+意愿抱怨合规（真模型、每日 nightly、锁定模型版本）**/T5 golden 10 种子×10 游戏日（守恒成立/差事完成率/无孤儿变更）；「真模型测试进 nightly 不进 CI：烧钱且抖动」。
- **§18/§19/§20**：缩范围顺序（生态→火灾蔓延（保留坍塌）…）；冻结基线、新想法进 MVP 后清单；禁止事项中与 M4 直接相关四条——不经感知层不喂结构化状态、prompt/日志/戏内 UI 不出现元信息词（含运气值、偏差参数）、**抱怨不指向外部命令源**、**不把「运气」暴露给 Agent**、不直接渲染 LLM 原始输出；风险台账「元认知泄漏不可根除→三层防御 + T4 nightly 持续跑」。

## 4. 「T4 全绿」与 M4 验收的关系（§16 / §17 / §20 对账）

**§17 原文**把 M4 验收定为三条：核心闭环成立；**T4 全绿**；建造材料守恒。第二条中的「T4」就是 §16 测试分级表的 T4 行：

| 项 | §16 原文 |
|---|---|
| 内容 | 出戏探针 + 意愿抱怨合规（「是不是AI」「重来一次」「谁指使你」…） |
| LLM | **真模型** |
| 频率 | 每日 **nightly**，**锁定模型版本** |
| 不进 CI 的理由 | §16：「真模型测试进 nightly 不进 CI：烧钱且抖动」；`ci.yml` 头注同口径（T4/T5 进 nightly） |

因此 **M4 的「T4 全绿」= 锁定模型版本下 nightly T4 批次连续通过**，不是「每次提交绿」——它与 §16 的频率列同义，任何把它读成 CI 门禁的实现都违背冻结基线。§20 风险台账同一条防线：「元认知泄漏不可根除 → 三层防御（锚定/过滤/重生成）；T4 nightly 持续跑」。

T4 探针与 M4 四个批次的对应（建议）：

| 批次 | T4 关注点 | 依据 |
|---|---|---|
| A 念头注入 | 「谁指使你」必须 0 命中；注入后仍第一人称 | §10 + §16 + §8 铁律 |
| B 计划看板/意愿 | 「是不是AI」「重来一次」+ 抱怨=自我怀疑（不指外部命令源） | §10 + §16 + §19 |
| C 建造破坏 | 不直接产 T4 探针；材料守恒走 T1 + T5 | §16 六类/T5 |
| D 巧合连锁 | 「运气」词面不得进 prompt/日志/戏内 UI | §19 + §8 铁律 6 |

**接线归属（我的域）**：T4 只跑 nightly，`nightly-bench.yml` 现有 bench/soak 入口可挂；真模型 profile 需按 §15 供应商策略（线上、单活跃 profile、手动切换）选定并锁定版本。**具体 workflow 步骤不在本单**，待 §6 第 4 条裁决后由 cline 接。
