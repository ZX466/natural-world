## 1. 判定体例（沿 K12/K13，零变更须论证）

沿用 K12 §1 与 K13 §4 的三问判定，逐事件回答（结论见 §2）：

| #    | 判定问                                               | 口径来源                                                                                                                                                         |
| ---- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 问 1 | 它是**事件流 kind**还是 **WS 帧 type**？             | 新 kind 只进 `EventKind`/`PAYLOAD_MODELS`（K11 P3/K13 ③），**不进** `WsMessage` 帧 type 闭合集（codex 红线 A① 钉）⇒ 零快照变更                                   |
| 问 2 | 若需玩家可见，**既有载体能不能承载**？               | `state_delta`（render 通道）已有 `actors[]`/`lights[]`/`structures[]`/`weather`/`plan[]`；`/api/world/map` 静态资产。找**自由字符串/既有枚举**的位置 ⇒ 零 schema |
| 问 3 | 它有没有**出戏边界**问题（内部数值/归因/权力语义）？ | D-10（权力不可见）、K13 §3 归因封堵三条、WS 咽喉闸（`outbound_guard.py`）                                                                                        |

**判定词汇**：**零变更**（`shared/` 零 diff）／**需投影**（复用既有载体，仍零 schema）／
**需新字段**（minor，须 §7 登记 + 升版）／**需新帧**（最高成本，撞闭合集钉 + 违 §3 一帧承载 ⇒ 默认否决）。

## 2. 四事件逐个判定

### 2.1 `ecology.shift` —— **零变更**（零投影）

- **语义**：生态链位移（砍树 → 水土流失 → 河浊 → 鱼少）。DESIGN §18 缩范围序第 1 位，最易砍。
- **判定**：**事件流**（`ecology.shift` 或按成因拆 `ecology.<cause>`，命名随施工），**不进帧**。
- **论证三条**：
  1. **问 1**：生态位移是**世界真相**（河水的浑浊度是物理事实），玩家不需要一个「生态数值」端点
     ——与 K12 的火势同理（`Light.kind` 自由串承载可见面，数值不出网关）。
  2. **问 2**：若产品要「水变浑了」的**视觉**，既有 `Weather.visual` 是**自由字符串**
     （`shared/openapi.json::Weather.visual`：`{"type":"string"}`），塞 `"muddy"` 之类即可
     ——**零 schema 变更**，与 `Light.kind="fire"` 同款先例（K12 §2 论证 B）。
  3. **问 3**：生态位移**不得**携带「谁砍的」归因键（否则变成对 NPC 行为的问责表，见 §4）。
- **代价**：`EventKind` + `PAYLOAD_MODELS` 登记（闭合集，`extra="forbid"`），零 schema。

### 2.2 `fauna.tick` —— **零变更**（复用既有 `actors[]` 投影）

- **语义**：动物三只的存在与移动（DESIGN M6「角色(小满→苏婉→赵铁→**动物**)」——动物是**可见角色**，
  与前三位同类）。
- **判定**：**事件流**（`fauna.tick`，逐只移动或位置变更时产）**＋ 复用既有 `actors[]` 投影**，
  **不加任何字段**。
- **论证三条**：
  1. **问 2 关键证据**：`Actor`/`ActorDelta` 的 `sprite`、`anim`、`tint` 是**自由字符串/数字**
     （实测快照：`Actor.sprite={"type":"string"}`、`ActorDelta.anim={"type":"string"}`），
     `facing` 是四值枚举（`n/e/s/w`）——**动物用不同 sprite 即可出现在既有载体里，零 schema 变更**。
  2. **问 1**：动物移动本身只进事件流（可重放面），**不进帧 type**；前端不需要「动物帧」，
     它只需要在 `actors[]` 里看到一只新的 rtoken。
  3. **命名纪律**：动物**不得**进 `actors[]` 之外的任何新数组（不新增 `fauna[]`）——那才是 schema 变更。
- **⚠ 事件预算**（沿 codex **W-D3** 口径）：`fauna.tick` **不得 per-tick 产事件**——判据「位置未变则零事件」。
  三只动物的移动频率天然低，但**寻路抖动**会把事件量放大 ⇒ F3 里写死。
- **代价**：`EventKind` + `PAYLOAD_MODELS` 登记；**零 schema**。

### 2.3 `speech.shift` —— **零变更**（零投影，且**邻接权力语义**）

- **语义**：语言阶层/识字率的位移（DESIGN §18 序第 3）。**这是四事件里安规风险最高的一个**。
- **判定**：**事件流**，**零投影**。
- **论证三条**：
  1. **问 1/问 2**：「语言阶层」若出站成数值或标签，就是**社会分层**的可枚举读数
     ——与 D-10「权力完全不可见」同一类问题（§4 展开）。
  2. **问 2 反面**：既有载体里**没有**合适的位置，且**不该新增**——`actors[]` 是位置载体，
     不是社会属性载体。
  3. **玩家可见的唯一合法形态**：**叙事**。「你认得那几个字」「这话你听不太懂」
     走既有 `monologue`/`perception` 文本面（过 `banned_words.scan()` 出站终扫 + `impulse_gate` 三扫）。
- **代价**：`EventKind` + `PAYLOAD_MODELS` 登记；**零 schema**。

### 2.4 `fog.reveal` —— **零变更**（本波），视觉语义留独立单（§3）

见 §3 专节（它是四事件里唯一有渲染语义的）。

## 3. `fog.reveal` 的特殊性：渲染语义 vs 一帧承载纪律

### 3.1 现状事实（决定方案空间）

| 事实                                                                                                             | 证据                                                                                              | 含义                                                                           |
| ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `FogOfWar` 已是**纯模块**（frozen、`reveal(cx,cy)`/`reveal_position`/`is_revealed`/`revealed_count`，区块 16px） | `sim/world/fog.py`                                                                                | 揭示的粒度是**区块**，天然适合投影成 `[{cx, cy}]`                              |
| `/api/world/map` **全量交付**地形静态资产（`MapInfo`+`MapChunk[]`，`collision_b64` 每格 1 bit）                  | 快照 `WorldMapResponse`                                                                           | **地形没有按需过滤** ⇒ 客户端本地就能画全图 ⇒ 要「变暗」必须知道哪些区块已揭示 |
| 客户端**零 fog 代码**                                                                                            | `client/src/**` 搜 `fog/revealed/explored` = 0 命中                                               | 视觉雾是从零做，不是「已有实现接线」                                           |
| `state_delta` **没有 fog 槽位**                                                                                  | 快照 `StateDeltaMessage`：`actors/lights/structures/plan/weather` ＋ `additionalProperties:false` | 走 delta 必须**加可选字段**（minor）                                           |
| `Weather.visual` 是**自由字符串**、`ambient_light` 是数字                                                        | 快照 `Weather`                                                                                    | 「雾天／视野变暗」可**零变更**表达——但它是**全局**光照，不是分区揭示           |

### 3.2 三个方案的判定

| 方案                             | 做法                                                                           | 协议代价                                                         | 判定                                                                                                                     |
| -------------------------------- | ------------------------------------------------------------------------------ | ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **A 服务端投影过滤**（推荐本波） | 未揭示区块的实体（actors/structures/lights）**不进 delta**；揭示本身只进事件流 | **零**（无字段、无帧）                                           | ✅ **本波采此**。它给的是「知识雾」：看不清的世界里没有生物与建筑。**局限要写明**：地形已全量交付 ⇒ **没有视觉变暗效果** |
| **B `state_delta` 加可选 `fog`** | `state_delta.fog = {revealed: [{cx, cy}, …]}`（**只在有新揭示时出现**）        | **minor**（扩可选字段 ⇒ §7 登记 + 升 minor + 快照/生成物同提交） | ⏸ **独立单**：仅当产品明确要「地图变暗」才做。**一帧承载 ✔**（复用 `state_delta`，不新增帧 type）                        |
| **C 新帧 `fog_reveal`**          | 新 WS 帧 type                                                                  | 撞 codex 红线 A①（帧 type 闭合集钉）＋违 versioning §3 一帧承载  | ❌ **否决**（K12 §5 待裁 4 同款：不为省一个字段破闭合集）                                                                |

### 3.3 推荐（B 的最小帧形状草案，供将来那一单直接抄）

```
state_delta.fog（**可选**，仅当本帧有新揭示时出现；形状封闭 additionalProperties:false）
  revealed: [{ cx: int, cy: int }, …]     # 本帧新揭示的区块（区块粒度 16px，对齐 FogOfWar）
```

- **为什么放 `state_delta`**：render 通道已是「可见世界变化」的唯一载体（一帧承载纪律）；
  `fog` 是**渲染态**，与 `weather`/`lights` 同族。
- **为什么必填 `cx/cy` 且无其它字段**：不返世界真相（区块尺寸/迷雾半径/视野规则）、不返 `tick/seq`
  （出戏边界同 `anchors-api` §0）。
- **零新枚举**：区块坐标是整数对，无枚举面。
- **收窄面纪律**：揭示只增（`FogOfWar` frozen + 并集语义），delta 只需发**增量**；
  重连全量走 `full_snapshot`（届时 `fog.revealed` 出现在快照帧里，仍是同一形状）。
- **本波明确不做**：B 属独立单（触发条件：产品要视觉雾）。本波只做 A ⇒ `shared/` 零 diff。

## 4. D-10 / 出戏边界核查（派单 ③）

**一句话判据（白盒负钉可直接照抄）**：四事件的**出站体**（事件 payload 的出站投影 + 任何帧段）
**零归因键、零权力语义键、零内部数值键**——键级判据用 `sim/api/outbound_guard.py` 的
**两层禁键集**（权力 9 键 + 随机流 7 键＋别名），归因键沿 K13 §5 的 `ATTRIBUTION_FORBIDDEN_KEYS`
（`actor_id`/`igniter`/`cause`/`culprit`/`blame`/`attribution`/`responsible`/`ordered_by`…），
**白盒扫 `sim/` 出站构造点**（`sim/api/**` 的字符串字面量 + 各模块的 `PAYLOAD_MODELS` 键集）。

| 事件            | 归因风险                             | 权力语义风险                                               | 内部数值风险                                               | 结论                                                                            |
| --------------- | ------------------------------------ | ---------------------------------------------------------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------- |
| `ecology.shift` | **高**：「谁砍的树导致河浊」＝问责表 | 中： blame 到具体 NPC 就成了权力叙事                       | 低：浑浊度是物理量，但不必出站                             | payload 只写**类目 + 位置**，不写 actor                                         |
| `fauna.tick`    | 低                                   | 低                                                         | 低：坐标是位置（`rtoken` 已脱敏），**数量/物种统计不出站** | `actors[]` 只出 `rtoken/x/y/sprite/anim/facing/tint`                            |
| `speech.shift`  | 中                                   | **最高**：语言阶层＝社会分层＝权力的**影子**（D-10 B2/B3） | **高**：识字率/阶层级别是**可枚举的社会指标**              | payload 只写**布尔式可达性变化**（某流派的字 now 可读），**禁**写层级/人数/排名 |
| `fog.reveal`    | 低                                   | 低                                                         | 中：区块尺寸/迷雾半径/视野规则属世界真相                   | 只出 `cx/cy` 增量                                                               |

**三条硬纪律（给施工与钉子）**：

1. **事件 payload 零归因键**（K13 §5 双保险同款：与数据面 `extra="forbid"` 互补，面不同）。
2. **`speech.shift` 禁写「社会分层数值」**：语言阶层的可见性只能是**自述式叙事**
   （「这字我认得」），不得由系统告知「你现在处于第几层」。
3. **雾不返世界真相**：`FogOfWar` 的内部表示（区块尺寸、半径、揭示集合大小）零出站；
   揭示只以**增量区块坐标**出站（若将来做 B）。

## 5. 对 Claude 施工的接口要求清单（F1–F5 体例，签名假设）

> 写法沿 K12 §4（F1–F5）与 K11 §6（P1–P5）：**签名可微调，纪律不可让**。

**假设 C1（事件落点与签名）**：四事件一律经 `store.append` 产**事件流**，
kind 登记 `EventKind` + `PAYLOAD_MODELS`（闭合集、`extra="forbid"`）。
建议签名（同款命名随你定）：

```python
# 建议形态（key 类别不可增，§4 四条硬纪律）：
ecology_shift(branch_id, *, kind_of_shift: str, x: int = 0, y: int = 0) -> None: ...
fauna_tick(branch_id, *, actor_id: str, x: int, y: int) -> None: ...          # actor_id 是内部 id，出站脱敏
speech_shift(branch_id, *, reach: Literal["read","comprehend"], stream: str) -> None: ...
fog_reveal(branch_id, *, cx: int, cy: int) -> None: ...
```

**纪律**：① 一切火/生态/ fauna/迷雾状态变更**必须经 `store.append`**（禁直写表，W-D1 同款）；
② **禁内存态**（状态必须是事件流纯函数投影，否则读档回来世界就变了）；
③ `fauna_tick` **不得 per-tick 产**（位置未变零事件，W-D3 口径）；
④ payload **零归因键/零分层数值**（§4）。

**假设 C2（帧投影面：零字段）**：动物走既有 `state_delta.actors[]`（`sprite` 自由串），
生态视觉走既有 `Weather.visual`（自由串）——**本波不得新增任何 WS 字段或帧 type**。
若施工认为需要 ⇒ 停，走 CR（K12 §5 待裁同款）。

**假设 C3（迷雾视觉 = 独立单）**：`state_delta.fog`（可选、仅增量）属**独立施工单**
（§3.3 草案已写死形状），须走 versioning §7 **minor** 登记 + 升版 + 快照/生成物同提交；
**不得**在本波顺手加（否则又一次「零变更」破功，且前端无渲染实现）。

**假设 C4（出站面继承 K11 咽喉闸）**：四事件的任何出站投影都经
`ConnectionManager._send_to`（K11 闸门，两层禁键同一递归）；**禁**为内容面另开发送路径。

**假设 C5（钉子同款）**：施工侧随落随钉（先红后绿或 skip-locked 双态，锁信号＝模块落地）：
每事件 ≥1 钉（kind 登记 + payload 封闭 + 零禁键），迷雾若做 B 另加「帧形状 + `shared/` 零 diff」
两钉；**钉子命名**建议 `test_m6_content_events.py`（入 `test_m6_*.py` glob ⇒ 自动进 CI）。
