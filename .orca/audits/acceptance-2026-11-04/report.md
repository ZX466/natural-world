## 缺陷 1（新，严重）土坎点不中：字形可见 → 挖到身后高块

**现场复现**（`R-wrong-dig.png` / `T-clickmark.png`，点击点用红圈标出）：

- 人物站 (90,33)，点土坎 (91,30) 顶面中心 → 服务端挖掉的是 **(92,31) h=2 石**，行囊 石+1。
- `pickVoxel` 的预测与实际一致（都指向 (92,31)），即**不是网络/服务端问题，是拾取排序问题**。

**根因**（`client/src/game/render/voxel-picking.ts::pickVoxel`）：

```ts
const rank = (height >= 2 ? 1000000 : 0) + depthKey(x, y);
```

「高方块优先」压过了深度序。等距投影下，一个 h≥2 的块会与它**斜后方**的 h=1 土坎顶面
覆盖同一个屏幕点；土坎虽然画在前面（`depthKey + 0.5`，字形像素实测可见），
拾取却选了画在后面的高块。

**全图量化**（真实地图，非夹具）：

| 口径 | 数值 |
|---|---|
| 土坎总数 | 1568 |
| 被更靠前格完全遮挡（点了也不该命中） | 1120 |
| 未被遮挡的土坎 | 448 |
| 其中点中心能命中自己 | **149（33.3%）** |
| 其中点中心命中**身后的高块** | **299（66.7%）**（`frontTall=0`，全部是「身后」） |

出生点视野内抽样（`V-day.json`，14 个土坎）：10 个字形像素可见，其中 **8 个点中心挖到别处**。

**影响**：验收项 8「1568 格隐形墙是否一眼可辨」不成立——比隐形更糟：玩家看见土坎、点土坎，
挖掉的是别的方块。第十一轮的视觉修复本身有效（`BANK_DARK/BANK_LIGHT` 精确色像素在 1440 截图里
1188/1212 个），**拾取层没跟上**。

**修法方向**（已派 codex 第二十二轮，**已收编**）：
`pickVoxel` 增可选第六参 `isBank(x,y)`；只有土坎**实际三道斜纹像素**与高块同池，
按 `depthKey+.5` 与绘制同序。不能全局深度优先（普通低地面会抢房屋侧面），
也不能整块顶面提升（空白处实际显示身后房屋侧面）。

**修后实测**（同一张未改的真实静态图，主树独立复跑 codex 的 `measure.cjs` 得到同读数）：
土坎点中心自命中 **149/448 → 448/448**；房屋/高块 **7141/7373 不变**；
可走面 **3947/3947 不变**；`pickGround` 逐字未动。
真实 E2E：站 (99,32) 长按 (99,31) 土坎顶面 → `voxelEdits` 只新增 `99,31`，土 0→1。

## 缺陷 2（新，中）转述把说话人记成转述者自己

**现象**（16x 3 分钟采样，去重 269 条 chatter，其中「听X说」92 条）：

```
听魏船工说，彭花匠，今天镇上有什么新鲜事？      ← 说话人写成转述者「魏船工」
听喻桶匠说，喻桶匠，我先去忙，回头聊。          ← 内容里还带着对方的名字
听严药童说，严药童，改天一起喝一杯。
```

92/92 全部如此；1x 60 秒独立采样 5/5 同样。**系统性，非偶发。**

**根因**（`sim/npc/sim_exec.py:787`）：

```python
_tick_src, _content = _prior_mems[-1]        # 只存了 (tick, content)
_speaker = (display_name_of or {}).get(npc_id, npc_id)   # npc_id = 转述者本人
_line = retell_template(_speaker, _content)
```

`ChatLedger.remember()`（`sim/npc/chat_ledger.py:41`）只落 `(tick, content)`，**说话人没落**，
转述时只能拿转述者自己的名字填模板。`test_e2_retell.py` 只钉了模板函数本身
（`retell_template("赵铁柱", …) == "听赵铁柱说，…"`），钉不到归因错误。

**修法方向**：记忆缓冲加 speaker（`remember(owner, content, tick, *, speaker_name)`），
转述用原说话人；补一条「转述内容中的说话人 ≠ 转述者」的测试。

**2026-11-04 已修（主树，用户裁定「简单问题你改」）**：
`ChatLedger.remember` 增必填 `speaker`，记忆条目变 `(tick, text, speaker)`；
`sim_exec.py` 转述改署记忆里的原说话人；`main.py` 两处解包跟着改。
RED→GREEN：`test_remember_keeps_speaker` + `test_retell_attributes_original_speaker_not_reteller`
（变异测试验证：把 `_said_by` 换回 `npc_id` 即红）。

**第一版修得不全（实机复验抓到，单测抓不到）**：改完第一次实机 3 分钟采样
**37/62 仍自指**。样本「听奚船家说，韩书生，吃了没？」——`sim_exec.py` 会把说话人
**自己**那句也落进自己记忆（`remember(npc_id, …, speaker=npc_id)`），于是
`_prior_mems[-1]` 常是本人台词。**转述自己说的话不叫转述**。
第二版改「取最新一条**不是自己说的**记忆」（`_heard_mems = [m for m in _prior_mems if m[2] != npc_id]`），
无外人之言时干脆不转述。新增 2 条测试：
`test_retell_skips_own_words_picks_other_speaker` / `test_retell_skipped_when_only_own_words`。
另把 `test_villager_with_memory_retells_on_chat_beat` 与冷却测试的夹具从「自己说自己」
改成「别人说的」（否则它们在新语义下测不到目标行为）。

**第二版实机复验（2026-11-04 19:37–19:41，同一隔离库、新进程）**：
