# 第十四轮：健康档写入与人物驱动

基线：3603ecb；协议保持 1.14，客户端零改动。只在 Codex 树提交，由主树收编。

1. RED：锁住总线漏注册、健康投影事务/分支隔离、fork 属性漂移、坍塌幸存者、隐藏事件执行桥及战斗感知缺失。
2. 事件与数据库：追加健康事件，复用 HiddenCategory；0015 回填历史 code 并建立分支/人物/code 唯一键；内容提供词面，事件只带内部键和状态。
3. 来源与装配：六条名角种子幂等入库；坍塌事件衍生健康事件；NPC 和陈默均以每十 tick 的感知帧评估触发窗口，提交后刷新健康缓存，读档时按新分支重装。
4. 陈默本轮接线：hidden provider 进入执行闸门、感知记忆与降格写回；异步模型返回及对白发送前复核窗口；回忆中未触发词面不进入 prompt。修复交手提示覆盖感知供数的顺序错误。
5. 隔离验证：临时 SQLite 验证迁移升级/降级、同事务回滚与父子分支；可控模型替身验证决策。录制八项派单证据并运行全部门禁。

风险与取舍：不演进每日严重度，不恢复进程内 HP，不进行付费模型调用；种子只补现有档案，避免复活死者。健康缓存仅在提交或读档后访问数据库；决策节拍只做纯函数计算。旧记录 code 使用旧 id 的十进制文本，保留已有属性标识。
